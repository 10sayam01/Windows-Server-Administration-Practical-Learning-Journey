### Step 1: Initial Verification
Server 1 > Server Manager > Tools > Active Directory Users and Computers > abc.com > Domain Controllers.

Verify that Server 2 is currently configured as an Additional Domain Controller (ADC).


### Step 2: Force Removal of Server 2
Server 2 > Server Manager > Manage > Remove Roles and Features > Next > Next > Server Roles > Active Directory Domain Services (AD DS) > Remove Features > Demote this domain controller > Force the removal of this domain controller > Next > Check Proceed with removal > Next > Enter Local Administrator Credentials > Next > Demote > Close.

Server 2 will automatically restart after the demotion process.


### Step 3: Metadata Cleanup – Delete from Active Directory
Server 1 > Server Manager > Tools > Active Directory Users and Computers > abc.com > Domain Controllers.

Right-click Server 2 > Delete > Yes > Check Delete this Domain Controller anyway and permanently remove the metadata > Delete > Yes.


### Step 4: Metadata Cleanup – Delete from DNS
Server 1 > Server Manager > Tools > DNS > Server > Forward Lookup Zones > abc.com.

Right-click the Server 2 DNS record > Delete > Yes.


### Step 5: Metadata Cleanup – Delete from Active Directory Sites and Services
Server 1 > Server Manager > Tools > Active Directory Sites and Services > Sites > Default-First-Site-Name > Servers.

Right-click Server 2 > Delete > Yes.
