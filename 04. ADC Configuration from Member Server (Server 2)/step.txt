### Step 1: Initial Verification
Server 1 > Server Manager > Tools > Active Directory Users and > abc.com >

- Domain Controllers: Verify that Server 2 is not listed.
- Computers: Verify that Server 2 currently exists as a Member Server.

### Step 2: Installing Active Directory Domain Services (AD DS)
Server 2 > Server Manager > Manage > Add Roles and Features > Next > Next > Next > Server Roles > Active Directory Domain Services (AD DS) > Add Features > Next > Next > Next > Install.


### Step 3: Promoting Server 2 as an Additional Domain Controller (ADC)
Server Manager > Notifications > Promote this server to a domain controller > Add a domain controller to an existing domain > Domain: abc.com > Next > Set Directory Services Restore Mode (DSRM) Password > Next > Next > Next > Next > Next > Install > Close.

Server 2 will automatically restart after the promotion process.



### Step 4: Final Verification
Server 1 > Server Manager > Tools > Active Directory Users and > abc.com

- Domain Controllers: Refresh and verify that Server 2 now appears alongside Server 1.
- Computers: Refresh and verify that Server 2 is no longer listed.

### Step 5: Creating Virtual Machine Snapshots
Open VMware Workstation > Snapshot Manager.

For Server 2:
Right-click Server 2 > Snapshot > Snapshot Manager > Take Snapshot > Name: ADC Create.

Repeat the same process for Server 1 and other lab devices, using the snapshot name **ADC Create**.
