### Step 1: Initial Verification
Server 1 > Server Manager > Tools > Active Directory Users and Computers > abc.com 

- Domain Controllers: Verify that Server 2 is currently listed as a Domain Controller.
- Computers: Verify that Server 2 is not listed in the Computers container.


### Step 2: Removing Active Directory Domain Services (AD DS)
Server 2 > Server Manager > Manage > Remove Roles and Features > Next > Next > Server Roles > Uncheck Active Directory Domain Services (AD DS) > Remove Features.


### Step 3: Demoting Server 2
Select Demote this domain controller > Next > Proceed with removal > Next > Enter Local Administrator Password > Demote > Close.

Server 2 will automatically restart after the demotion process.


### Step 4: Final Verification
Server 1 > Server Manager > Tools > Active Directory Users and Computers > abc.com.

- Domain Controllers: Refresh and verify that Server 2 is no longer listed.
- Computers: Refresh and verify that Server 2 now appears in the Computers container.
