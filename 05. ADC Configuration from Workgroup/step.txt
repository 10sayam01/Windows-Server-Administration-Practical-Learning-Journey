### Step 1: Initial Verification
Server 1 > Server Manager > Tools > Active Directory Users and Computers > abc.com > Computers

Verify that Server 1 is currently the only Domain Controller (DC) and Server 3 is not listed in the Computers container.


### Step 2: Server 3 Initial Configuration
Server 3 > Server Manager > Local Server > Verify the current Workgroup status.


### Step 3: Installing and Promoting Server 3 as an Additional Domain Controller (ADC)
Server 3 > Server Manager > Manage > Add Roles and Features > Next > Next > Next > Server Roles > Active Directory Domain Services (AD DS) > Add Features > Next > Next > Next > Install.

After installation:

Server Manager > Notifications > Promote this server to a domain controller > Add a domain controller to an existing domain > Domain: abc.com > Change > Username: Administrator@abc.com > Enter Password > OK > Next > Set DSRM Password > Next > Next > Next > Next > Install > Close.

Server 3 will automatically restart after the promotion process.


### Step 4: Final Verification
Server 1 > Server Manager > Tools > Active Directory Users and Computers > abc.com > Domain Controllers.

Refresh the section and verify that Server 3 now appears alongside Server 1 as an Additional Domain Controller (ADC).
